## 📌 Problem Statement & Vision

Millions of Indian consumers purchase everyday goods without knowing if they meet Indian Quality Standards—or if the ISI certification mark on the product is genuine. Complex Indian Standards (IS documents) are often technical and difficult for the average citizen to understand.

**BIS Mitra** bridges this gap using **Multimodal Artificial Intelligence**, **Retrieval-Augmented Generation (RAG)**, and **Computer Vision** to deliver instant, plain-language answers, automated compliance checks, and real-time fake ISI detection.

---

## ✨ Key Features

### 1. 🤖 Multimodal RAG AI Engine
- Answers queries about **Indian Standards (IS Codes)**, product safety requirements, and certification rules.
- Real-time web grounding against official BIS registries with **zero-hallucination guarantee**.

### 2. 📸 AI Vision & OCR Scanner
- Point your camera or upload a product label photo.
- Automatically extracts CML (License) numbers, inspects ISI marks, and verifies compliance against BIS databases.

### 3. 🎙️ Multilingual & Voice AI Assistant
- Full support for Indian regional languages (Hindi, English, etc.).
- Interactive voice input and spoken audio responses for enhanced accessibility.

### 4. 🛡️ Counterfeit & Fake Mark Detection
- Flags invalid or revoked CML numbers in seconds to protect consumers from unsafe counterfeit products.

## 🚀 Quick Start (Local Setup)

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSVIBRUS/BIS-Mitra-.git
   cd BIS-Mitra-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   cd backend
   npm install
   cd ..
   ```

3. **Build and start the application:**
   ```bash
   npm run start
   ```

4. **Access the web app:**
   Open [http://localhost:5000](http://localhost:5000) in your web browser.
